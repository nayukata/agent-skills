# 翻訳辞書: 比喩・擬態語 → 実装

ユーザーの自然言語を実装値に翻訳するための逆引き辞書。
数値はすべて**初期値**であり、フィードバックで調整する前提。ユーザーには数値でなく比喩で報告する。

## 目次

- トーンの対
- 素材 → 表面の処理
- 景色 → 配色
- 擬態語 → モーション
- 物理法則 → モーションシステム全体
- 声 → タイポグラフィ
- 音
- 度合い語 → 調整量

## トーンの対

ユーザーが形容詞を単発で言ったら、対になる軸のどちら寄りかを確認すると精度が上がる。

| 軸 | 左に寄せる実装 | 右に寄せる実装 |
|---|---|---|
| 明るい ⇔ 暗い | 高明度の地、影は薄く | 暗い地、発光・ハイライトで導く |
| 静か ⇔ 賑やか | 要素数を絞る、動きは1箇所 | 同時多発の動き、色数を増やす |
| やわらかい ⇔ シャープ | 大きめの角丸、低コントラスト、ぼかし影 | 角丸なし、細い罫線、強コントラスト |
| すかすか ⇔ ぎっしり | 余白を倍に、1画面1トピック | 密度の高いグリッド、行間を詰める |
| 人肌 ⇔ 無機質 | 揺らぎ・非対称・テクスチャ | 完全整列、無地、システムフォント |
| 現実的 ⇔ 夢みたい | 実写・具体的なUI慣習 | 抽象形、グラデーション、浮遊 |
| 澄んでいる ⇔ 濁り | 純色に近い高明度色、透明感 | ノイズ、くすみ色、粒子 |
| 軽い ⇔ 重厚 | 細いウェイト、薄い影、速い動き | 太いウェイト、深い影、ゆっくりした動き |

## 素材 → 表面の処理

| 素材 | 実装の方向 |
|---|---|
| すりガラス | 半透明の白 + backdrop blur + ごく細い明るい縁取り |
| ガラス | 高い透明度、シャープなハイライト線、反射を1本 |
| 水・泡 | 半透明 + わずかな屈折表現、輪郭はやわらかく |
| 霧・もや | 大きなぼかし、境界を消す、彩度を下げる |
| 紙・和紙 | 純白でなく生成り、微細なテクスチャ、影は短くやわらかい |
| 綿・毛布 | 大きな角丸、低コントラスト、広くぼけた影 |
| ゼリー | 彩度のある半透明 + 弾性モーション（ぷるん参照） |
| 陶器 | つるっとした無地、ごく淡いグラデーション、影は接地部のみ |
| 金属・鏡面 | 高コントラストのハイライト帯、グラデーションの反射 |
| 石 | 低彩度、重く濃い影、動かさない |
| ネオン | 暗い地 + 発光色 + glow。使う場所は絞る |
| 絹 | 滑らかに流れるグラデーション、細い書体と相性 |

## 景色 → 配色

色コードの代わりに景色で指定されたときの変換。「役割」も添えて確認する（基本の色 / 差し色 / 締めの色）。

| 景色 | 配色の方向 |
|---|---|
| 朝の光 | 白ベース + 淡い黄・低彩度の青。高明度、影は青みに |
| 昼の日なた | 白とはっきりした色、コントラスト高め |
| 夕暮れ | 暖色のグラデーション、全体のコントラストを落とす |
| 夜明け前 | 濃紺〜藍 + わずかな暖色を地平に1点 |
| 曇りの日の白 | 純白でなく灰みの白、影も淡い |
| 雨上がり | 低彩度・高明度、澄んだ灰 + 洗われた緑や青 |
| 浅瀬の海 | 明るいシアン〜エメラルド、白を多く残す |
| 深海 | 暗い青緑、光は点や線で最小限 |
| シャボン玉の膜 | 白地 + 低彩度の虹色グラデーションを薄く |
| オーロラ | 暗い地 + 緑〜紫の流れるグラデーション |
| 絵の具を水で薄めた色 | 選んだ全色を白に寄せる（高明度・低彩度で統一） |
| 原色のまま | 彩度を落とさない。ただし面積を絞る |

## 擬態語 → モーション

| 擬態語 | 動きの性格 | 実装の初期値 |
|---|---|---|
| ふわっ | ゆっくり現れて浮く | 600–1000ms、ease-out、opacity + 小さめの上方向移動 |
| ぷかぷか | 常時ゆるやかに漂う | 3–6秒の無限ループ、要素ごとに位相をずらす |
| すっ / しゅん | 速く滑らか、余韻なし | 150–250ms、ease-in-out、オーバーシュートなし |
| ぽん / ぴょこん | 弾んで登場 | scale 0.9→1、軽いオーバーシュートのスプリング、300–500ms |
| ぷるん / ぼよん | 弾力、揺り戻し | スプリング（減衰弱め）、揺り戻しをはっきり見せる |
| とろり / ぬるっ | 粘って遅れてつく | 長めの duration + 強い ease-out。追従なら補間係数を小さく |
| ゆらゆら / たゆたう | 一定でない揺れ | 周期の違う揺れを合成し、完全な周期性を避ける |
| ぴたっ / かちっ | 精密に止まる | 100–200ms、強い ease-out、止まる位置を明確に |
| ざっ / ばっ | 勢い、大胆 | 大きな移動距離を短い時間で、ease-out |

## 物理法則 → モーションシステム全体

「世界の物理法則」が決まったら、**すべての動き**に同じ法則を適用する。個別の要素だけ別の物理で動かさない。

| 法則 | システムへの翻訳 |
|---|---|
| 水の中みたいに | 全 duration を1.5〜2倍、イージングを緩く、静止時も微小な揺れ |
| 無重力みたいに | 常時ドリフト、重力・落下の表現を使わない |
| 羽が落ちるように | ゆっくりした下降 + 横方向の揺れ |
| バネ仕掛けみたいに | 全トランジションをスプリングに、オーバーシュートを許可 |
| 磁石みたいに | ポインタ近接で吸い付く、離れると戻る |

あわせて必ず確認する軸: **勝手に動く**（演出は自律的、操作に反応しない）のか、**触ったときだけ動く**のか。

## 声 → タイポグラフィ

| 声 | 実装の方向 |
|---|---|
| やわらかい声 | 丸みのあるゴシック or 低コントラストのサンセリフ、字間ややゆったり |
| きりっとした声 | シャープなサンセリフ、ウェイト差で締める |
| 事務的な声 | システムフォント、装飾なし、サイズ差も控えめ |
| 手書きの声 | 手書き風書体は1箇所限定（乱用するとチープになる） |
| ゆっくり話す | letter-spacing と line-height を広く |
| 早口・詰まってる | 字間標準〜狭め、行間も詰める |
| 大きな声は1箇所だけ | 見出しサイズの大ジャンプは1画面1回まで |

## 音

音を扱う場合も同じ話法で翻訳する。

- **材質**: 「ガラスを弾いた音」「水滴」「木を叩いた音」——素材語彙をそのまま音色選定に使う
- **距離**: 「遠くで鳴ってる」= 音量小 + リバーブ、「耳元」= ドライで小さく
- **役割**: 「主役の音」は1つ、他は「気づくか気づかないか」の音量に
- 世界観が決まっているなら、すべての音を同じ系統（同じ「親戚」）で揃える

## 度合い語 → 調整量

フィードバックの微調整はこの換算で受ける。

| 度合い語 | 換算 |
|---|---|
| 気持ちだけ | 10〜15%の変化 |
| 一段 | 定義済みスケール（サイズ・余白・ウェイト）の1ステップ |
| 半分 / 3割減 | 文字どおりの割合 |
| 思い切って | 2倍以上、または手法ごと変える |
