# デザインブリーフ: 7スロットと仮埋めの作法

デザインの指示は、突き詰めるとこの7つのどれかの話をしている。

| # | スロット | 問いの形 |
|---|---|---|
| 1 | 目的 | 誰が見て、何を持ち帰る画面か |
| 2 | トーン | どんな空気の場所か（形容詞2つまで + 明るい/暗い） |
| 3 | 色 | どんな景色・時間帯・天気の色か |
| 4 | 文字 | 声にしたらどんな声か |
| 5 | 比喩 | 世界観を貫くモチーフを **1つ** |
| 6 | 動き | この世界の物理法則は何か + 勝手に動くか、触ると動くか |
| 7 | 見せ場 | 一番記憶に残したい瞬間は **1箇所** |

## 構造ルール

- **比喩は1つ、見せ場は1箇所**。2つ以上あると「全部盛りで安っぽい」に落ちる。ユーザーが複数出したら、どれを主役にするか選んでもらう
- **トーンの形容詞は2つまで**。3つ目はたいてい矛盾を生む（例:「幻想的でポップでかっこよく」）
- 目的（#1）が決まらないうちに他を埋めない。目的が変わると全部変わる

## 仮埋めの作法

1. ユーザーの発言・プロダクトの性質・利用者像・既存画面・参照 URL から、7スロットすべてを**具体的な仮説**で埋める
2. 埋めた根拠が薄いスロットに「？」を付ける
3. 表にして見せ、「こだわりがある欄だけ直して。あとはおまかせでいい」と返してもらう
4. 「？」付きのスロットで方向が割れるものは、モック比較の論点に回す

仮埋めの品質基準:

- **悪い仮埋め**: 「シンプルで見やすく」「モダンな配色」——誰も訂正できない。平均値をそのまま置いているだけ
- **良い仮埋め**: 「夕方に日報を書く疲れた人が対象だから、目に刺さらない『雨上がりの夕方』の色。声は事務的すぎず、隣の席の先輩くらいの距離感」——違ったら即「そこじゃない」と言える

## 記入例

社内日報アプリのトップ画面を「いい感じに」と頼まれた場合の仮埋め:

| スロット | 仮の答え | 確信 |
|---|---|---|
| 目的 | 一日の終わりに開く画面。「今日も書き終えた」という区切りを持ち帰る | |
| トーン | 静かで、やわらかい。明るさは日中より一段落とす | ？ |
| 色 | 夕暮れの窓辺。白地に暖色をほんの少し | ？ |
| 文字 | 隣の席の先輩の声。事務的すぎず、砕けすぎず | |
| 比喩 | 一日を閉じる「しおり」 | ？ |
| 動き | 触ると動く。勝手には動かない（業務画面なので） | |
| 見せ場 | 送信した瞬間の、静かな完了の合図 | |

「？」が3つあるので、トーンと色と比喩を対比させた2〜3案のモックを次フェーズで見せる。
