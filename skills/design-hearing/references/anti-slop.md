# ありがちパターン禁止リスト

「AIが作った感」の正体は**平均値**。どのブリーフスロットも訂正されなかった部分が、一番ありがちな見た目に落ちる。
実装を見せる前に、以下のパターンに落ちていないか自己チェックする。

## 禁止パターンと代替

| 禁止パターン | 代わりにやること |
|---|---|
| 色付き左ボーダー + グレー背景のカード | 罫線・余白・タイポグラフィの階層で構造を出す。装飾で区切らない |
| 紫→青のグラデーション（特に見出し文字） | 色はブリーフの「景色」から導く。景色が決まっていないならそれを先に決める |
| 装飾としての絵文字 | 世界観のモチーフから記号を自作する（SVG・CSS）。比喩が泡なら泡から、紙なら紙から導く |
| 均一な角丸カードの3枚横並び | 内容の重要度に差があるなら、レイアウトにも差をつける（非対称・サイズ差） |
| 全要素に hover で scale 拡大 + 影 | インタラクションも世界の物理法則から導く。法則がないなら動かさない選択もある |
| 意味のないグロー・ぼかした色玉の背景 | モチーフが要求する場合のみ。「なんとなく今風」で置かない |
| 見出しも本文も同じサンセリフの均一ウェイト | 「声」のブリーフから書体を選ぶ。見出しには声の個性を出す |
| 装飾が情報より先に目に入る | 装飾の主役は「見せ場」の1箇所に集中させ、他は脇役に下げる |
| すべてのセクションが同じリズム（見出し+説明+カード群の繰り返し） | 1箇所だけリズムを崩す。見せ場がその候補 |

## 「AIくさい」と言われたときの対処

1. 上のリストと照合し、どのパターンに落ちているか特定する
2. 該当がなければ、ブリーフのどのスロットが「平均値のまま」かを探す（訂正されなかったスロットが怪しい）
3. そのスロットを対比の効いた2案で見せ直し、方向を取り直す

パターン指摘を待たずに済むのが理想。見せる前のセルフチェックでこのファイルを1周する。
