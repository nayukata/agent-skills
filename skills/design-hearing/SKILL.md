# Design Hearing

ユーザーの頭の中にある曖昧なイメージを、対話とモックで具体化してから実装する。
デザインの語彙力をユーザーに要求しない。引き出す・翻訳する・見せて選ばせるのはこちらの責務。

## 原則

1. **言われなかったことは平均値で埋まる**。平均値で埋めると「一番ありがちな見た目」になる。だから仮定を隠さず見える化し、訂正の機会を渡す。
2. **仕様を語らせるより、実物に反応させる**。人は「何が欲しいか」は言えなくても、「どれが近いか」「どこが嫌か」は即答できる。
3. **数値の話をユーザーに持ち込まない**。会話は比喩・擬態語・素材で行い、数値への翻訳はこちらの仕事。報告も比喩で返す。
4. **要望が曖昧なほど、このスキルの価値が高い**。「曖昧だから聞かずに適当に作る」は逆。

## 発動の境界

- **発動しない**: 既存デザインの世界観に従うだけの小さな1要素修正（色・余白・サイズの調整など）。新しい設計判断がないため
- **軽量発動**: 仕様や参照デザインが既に具体的なとき。ブリーフは頭の中で埋め、不明なスロットだけ言葉で確認する。表は出さない
- **フル発動**: 新規画面・新規サイトの作成、または「いい感じに」系の曖昧な依頼

## フロー

チェックリストを写して進捗を管理する:

```
- [ ] 1. ブリーフ仮埋め
- [ ] 2. 割れる論点をモックで絞る
- [ ] 3. 実装（比喩から数値への翻訳）
- [ ] 4. フィードバック反復
```

### 1. ブリーフ仮埋め

[references/brief.md](references/brief.md) を読み、7スロットのブリーフを作る。

- ユーザーの発言と文脈（プロダクトの性質・利用者・既存画面・参照 URL）から、各スロットを**具体的な仮の答え**で埋める。「シンプルで見やすく」のような無難な答えは仮埋めとして失格。訂正したくなる程度に具体的な仮説を置く
- 質問攻めにしない。埋めた表を見せて「こだわりがある欄だけ直して。あとはおまかせでいい」と返してもらう
- 自信がないスロットには印を付ける。そこが次フェーズのモックの論点になる

### 2. モックで絞る

モックを作る条件は2つ。**世界観レベルのスロット（トーン・比喩・色）に？が付いたとき**と、**新規画面・新規サイトのとき**（？の有無に関わらず、ゼロから作るものは一度実物で方向を確認してから本実装に入る方が手戻りが少ない）。？があるときは対比の効いた 2〜3 案を見せて選んでもらう。？が無く新規条件だけに該当するときは 1 案で方向確認だけでよい。細部レベルのスロット（文字・動き）の？は、モックにせずブリーフ表の中で言葉と度合いで確認する。

- 同じ平均値の亜種を並べない。別方向の案をぶつける（例: ミニマル / 情緒的 / 骨太）
- 1 ファイルの HTML モックで十分。ヒーロー相当の 1 画面分だけ、世界観が伝わる最小限を作る
- 環境で使える実物提示の手段で見せる（Artifact、ブラウザプレビュー、HTML ファイルを開いてもらう等）。コード片やテキスト説明で代替しない。見た目の議論は見た目でしかできない
- 選ばれた案を基準点にして、他の案から「ここだけ好き」が無いかも聞く

### 3. 実装

確定したブリーフを「この世界の法則」として一貫適用する。

- 比喩・擬態語・素材から実装値への翻訳は [references/vocabulary.md](references/vocabulary.md) を参照する
- すべての動きは同じ物理法則から、すべての色は同じ景色から導く。場当たりで足さない
- 見せる前に [references/anti-slop.md](references/anti-slop.md) の禁止パターンに落ちていないか自己チェックする

### 4. フィードバック反復

- 「くさい」「怖い」「微妙」「なんか違う」は正規の信号。ありがちパターンに落ちている警告として扱い、原因の言語化をユーザーに求めない
- 対象の特定を手伝う。「全部違う？それとも残したいところはある？」——**残すものを言ってもらう**のが一番効く
- 方向が合っているときの微調整は度合い語で確認する（半分 / 一段 / 気持ちだけ）
- ユーザーの違和感は世界の法則に昇格させる。例:「カーソルで動くのが嫌」→「演出は自律的に動き、操作に媚びない」という原則として以後すべてに適用する
- 変更報告は比喩で返す（「もっとゆっくり漂うようにした」）。数値の詳細は求められたときだけ出す

## ユーザーに渡せる資料

「デザインの伝え方を自分でも学びたい」と言われたら、[for-humans.md](for-humans.md)（人間側の語彙ガイド）を案内する。スキルの動作には不要なので、こちらから読み込む必要はない。
