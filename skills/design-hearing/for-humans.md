# デザインを自然言語で伝えるためのガイド（人間向け）

「いい感じにしたい」を、数値を一切使わずに意図通り伝えるための語彙集。ミリ秒やピクセルではなく、比喩や擬態語、対で語るトーンといった自然言語だけで、狙った見た目や手触りに着地させる方法をまとめたもの。実在するポートフォリオサイト制作の対話から生まれたもので、第5章のケーススタディはその実録である。

---

## 0. 前提: 役割分担

**方向を決めるのがあなた。数値に翻訳するのが AI。**

ミリ秒やピクセルやイージング関数は、こちらが口にした瞬間に「方向の話」が「実装の話」にすり替わってしまう。あなたが磨くべきは、**自然言語の解像度**——「幻想的」としか言えなかったものを「水中みたいに、ゆっくり、勝手に漂う感じ」と言えるようになること。それだけで翻訳精度は別物になる。

このガイドは、その解像度を上げるための「言葉の引き出し」を、大枠からディティールの順に並べたもの。

---

## 1. まず決める7つのこと（大枠）

デザインの指示は、突き詰めるとこの7つのどれかの話をしている。全部埋める必要はない。**言わなかったことは相手が平均値で埋める**（=一番ありがちな見た目になる）ので、こだわりがあるものだけ自分の言葉で埋める。

| 決めること | 問いの形 | ケーススタディでの答え |
|---|---|---|
| ① 目的 | 誰が見て、何を持ち帰る1枚か | 名刺がわり。人柄を持ち帰ってもらう |
| ② トーン | どんな空気の場所か（形容詞2つまで） | 明るくて、幻想的 |
| ③ 色 | どんな景色・時間帯の色か | 白い部屋にシャボン玉の虹色 |
| ④ 文字 | 声にしたらどんな声か | やわらかく、ゆったり話す声 |
| ⑤ モチーフ | 世界観を貫く比喩を**1つ** | 泡 |
| ⑥ 動き | この世界の物理法則は何か | 浮力。すべてがふわっと浮かぶ |
| ⑦ 見せ場 | 一番記憶に残したい瞬間はどこか | 泡が弾けて名前が現れる開幕 |

⑤と⑦は**1つに絞る**。比喩が2つあるサイトは、たいてい「全部盛りで安っぽい」になる。ケーススタディでは「自動組み立て」と「泡」の2案から泡に一本化した。

---

## 2. 語彙の引き出し（ディティール）

ここからが本体。軸ごとに「使える言葉のパレット」を並べる。ポイントは、**細かく言うほど数値に近づくのではなく、比喩に近づく**こと。

### 2-1. トーンは「対」で語る

形容詞を単発で言うより、**天秤のどちら寄りか**で言うと一気に伝わる。

- 明るい ⇔ 暗い
- 静か ⇔ 賑やか
- やわらかい ⇔ シャープ
- すかすか（余白たっぷり） ⇔ ぎっしり
- 人肌・手作り ⇔ 無機質・機械
- 現実的 ⇔ 夢みたい
- 澄んでいる ⇔ 濁り・ノイズがある
- 軽い ⇔ 重厚

使い方の例:「明るくて静か寄り。やわらかいけど、締まりは欲しい」——これだけで方向はほぼ確定する。

### 2-2. 質感は「素材」で語る

見た目の細部は、素材の名前を借りるのが最短。人類は素材の質感を全員が共有している。

ガラス / すりガラス / 水 / 泡 / 霧・もや / 紙・和紙 / 綿・毛布 / ゼリー / 陶器 / 金属・鏡面 / 石 / 木 / ネオン / 絹

例:「カードはすりガラスっぽく」「背景は霧がかかった感じ」「ボタンは陶器みたいにつるっと」。ケーススタディの「ガラス感のある音」も、素材語彙を音に転用した好例（そしてちゃんと通じた）。

### 2-3. 色は「景色・時間帯・天気」で語る

色コードの代わりに、その色がある場所を言う。

- 朝の光 / 昼の日なた / 夕暮れ / 夜明け前
- 晴れの白 / 曇りの日の白 / 雨上がり
- 水面の反射 / 浅瀬の海 / 深海
- シャボン玉の膜 / 貝殻の内側 / オーロラ
- 絵の具を水でうんと薄めた色 / 原色のまま

あわせて**色の役割**を一言:「基本は◯◯、差し色に◯◯、締めに◯◯を1点だけ」。ケーススタディでは「白い部屋+シャボン玉の虹色+濃い紫を1点」だった。

### 2-4. 動きは「擬態語」と「物理法則」で語る

日本語の擬態語は、モーション指示のためにあると言っていいくらい優秀。恥ずかしがらずに使う。

**擬態語パレット**
- ふわっ / ぷかぷか — 浮く、ゆっくり現れる
- すっ / しゅん — 素早く滑らかに、余韻なく
- ぽん / ぴょこん — 弾ける、跳ねる
- ぷるん / ぼよん — 弾力、揺り戻し
- とろり / ぬるっ — 粘性、遅れてついてくる
- ゆらゆら / たゆたう — 一定でない揺れ
- ぴたっ / かちっ — 精密に止まる
- ざっ / ばっ — 勢い、大胆

**物理法則で語る**（世界全体の動きを一言で決められる）
- 「水の中みたいに」= 全部ゆっくり、抵抗がある
- 「無重力みたいに」= 漂う、落ちない
- 「羽が落ちるように」= ゆっくり、揺れながら
- 「バネ仕掛けみたいに」= 勢いよく、行きすぎて戻る
- 「磁石みたいに」= 近づくと吸い付く

**主語と因果を言う**
- 「勝手に動いていてほしい」⇔「触ったときだけ反応してほしい」
- 「カーソルに反応するのは嫌」= 演出は自律的であれ、という立派な方向指定

### 2-5. 音は「材質・距離・景色」で語る

音こそ数値では絶対に語れない領域。でも自然言語なら語れる。

- 材質で:「ガラスを弾いた音」「水滴」「木を叩いた音」「金属っぽいのは嫌」
- 距離・大きさで:「遠くで鳴ってる感じ」「耳元でささやく程度」「主張しすぎ、半分くらいに」
- 景色で:「洞窟の水滴」「風鈴」「グラスハープ」「ゲームのレベルアップ音みたいなのは違う」
- 役割で:「主役の音」「気づくか気づかないかの音」

### 2-6. 文字は「声」で語る

書体の知識は不要。その文字が喋ったらどんな声か、で伝わる。

- やわらかい声 / きりっとした声 / 事務的な声 / 手書きの声
- ゆっくり話す（字間ゆったり） / 早口（詰まってる）
- 大きな声は1箇所だけ / 全体的に小声

### 2-7. 量とバランスは「引き算」で語る

- 「主役は1つ。ほかは脇役に下げて」
- 「賑やかすぎる。3割減らして」「半分にして」
- 「一段だけ控えめに」「気持ちだけ強く」
- 「なくても成立するものは消して」

度合いの言葉（半分 / 一段 / 気持ちだけ / 思い切って）は、数値を使わずに量を指定できる万能語。

## 3. 精度を上げる4つの話法

語彙が思いつかないときでも、この話法に乗せれば伝わる。

1. **比喩:**「◯◯のような」— シャボン玉のような、水族館のような、深夜のコンビニのような。
2. **対比:**「AよりB寄り」「AとBの中間」「前のやつと同じタイミングで、別の音」— 基準点があると翻訳精度が跳ね上がる。
3. **度合い:**「もっと / やや / 半分 / 一段だけ」— 方向は合っている時の微調整はこれだけでいい。
4. **参照:**URL・作品名・固有名詞を貼る — 好きなものの固有名詞は、形容詞10個分の情報量がある。

そして話法以前の大原則:

- **対象を特定する。**「音が微妙」ではなく「泡の音はいい。それ以外が好みじゃない」。残すものを言うのが特に効く。
- **症状だけ報告すればいい。**「クリックが1回しか効かない」— 原因の推測は不要。それは相手の責務。
- **「〜くさい」は有効な言葉。**「AIくさい」「シンセくさい」は、ありがちなパターンに落ちているという警告としてちゃんと機能する。
- **違和感はその場で言う。**後でまとめて言うと文脈が消える。

---

## 4. アンチパターン

- **「おしゃれにして」だけ** — 7つの問いのどれにも答えていない。全部を相手の平均値で埋められる。
- **形容詞3つ以上の全部盛り** — 「幻想的でポップでかっこよく」。トーンは2つまで。3つ目は矛盾を生む。
- **比喩の複数指定** — 「泡と歯車と星空で」。世界は1つの比喩から導く方が強い。
- **手段から入る** — 「3Dで」「パーティクルで」から入ると、何を感じさせたいかが置き去りになる。手段の選定は相手の責務。
- **数値で指示する** — 「0.3秒で」「20px空けて」。方向の対話が実装のレビューにすり替わる。感じたことを言えば、数値は向こうが探す。

## 5. ケーススタディ: ポートフォリオサイトの翻訳ログ

依頼者の発言（すべて自然言語）が、そのまま設計判断になった記録。**この程度の言葉で足りていた**ことが最大の教訓。

| 依頼者の言葉 | 決まったこと |
|---|---|
| 「ユニークでゲームライクな演出」 | 見た目ではなく演出の文法（開幕・遷移・ご褒美）を採用 |
| 「成果物が増えても困らない設計に」 | 記事・リポジトリの自動同期。作品はデータ1件足すだけの構造 |
| 「右から左に流れるスクロール」 | 作品棚は横に流れる見せ場に |
| 「暗いイメージは避けたい」 | 世界のベースは白・明るい、で確定 |
| 「名刺がわりの自己紹介」 | 作品一覧より人柄を優先する構成に変更 |
| 「綺麗め、幻想的。泡がいい」 | 世界観の比喩を泡に一本化。トーンをポップから透明感へ修正 |
| 「猫は控えめでもいい」 | 主役級→小ネタ級へ、存在感の量を指定 |
| 「猫が怖い。シルエットの方がいい」 | 小さな装飾キャラは描き込むほど怖くなる、という品質判断 |
| 「泡の音はすごくいい。それ以外が好みじゃない」 | 音は全部「泡の親戚」で統一、という設計原則に昇格 |
| 「ガラス感のある音ないかな」 | 素材語彙の転用。完璧な指示 |
| 「カーソルで泡が動いてしまう」 | 演出は自律的に動く（操作に媚びない）という世界の法則 |
| 「絵文字はAIくさい」 | 記号は世界観（泡）から自作する、という装飾原則 |

## 6. 依頼テンプレート

新しくデザインを頼むときの穴埋め。全部自然言語で埋まるようになっている。埋まらない欄は「おまかせ。ただし◯◯は避けて」でいい。

```
【目的】誰が見て、何を持ち帰る画面か:
【トーン】空気を形容詞2つまで+明るい/暗い:
【参照】近いイメージのURL・作品・場所（あれば）:
【比喩】世界観の中心を1つ（なければ「提案して」）:
【動き】この世界の物理法則（水中/無重力/バネ… + 勝手に動く/触ると動く）:
【見せ場】一番記憶に残したい瞬間:
【避けたいもの】:
【運用の条件】更新の手間、増えていくもの、見る環境など:
```

記入例（ケーススタディのサイトを最初からこのテンプレで頼む場合）:

```
【目的】名刺がわりの自己紹介。人柄を持ち帰ってもらう
【トーン】明るくて幻想的
【参照】Awwwards にあるスクロールで魅せる系のサイト
【比喩】泡
【動き】水の中。すべてふわっと浮かぶ。演出は勝手に動いていて、カーソルには反応しない
【見せ場】初回だけの開幕演出。泡が弾けて名前が現れる。スキップできること
【避けたいもの】暗い配色、絵文字、シンセくさい音、キャラの描き込みすぎ
【運用の条件】記事とリポジトリは勝手に最新になってほしい。作品は1件ずつ足せる形
```

## 7. 上達の仕方

引き出しは、この反復でしか増えない。

1. 作ってもらう
2. 違和感を、その場で、拙い言葉のまま言う（「怖い」「くさい」で構わない）
3. 相手の翻訳結果を見て、「ああ、あれはこういう言葉だったのか」と回収する
4. 気に入ったものには「なぜ気に入ったか」を一言添える（次回の基準点になる）

このガイドの語彙——**対で語るトーン、素材、景色の色、擬態語、物理法則、声、引き算**——を少しずつ手癖にしていけば、最初のひとことから狙った場所に着地できるようになる。
