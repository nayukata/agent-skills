# ファネル診断

「客が増えない」は原因が4種類ある。段階ごとに効く施策が違うので、先に詰まっている場所を特定する。
ボトルネック以外に手を打たない。

## 4つの詰まり方

| 段階 | 詰まりの症状 | 日常語での確認質問 | 効く打ち手の方向 |
|---|---|---|---|
| 認知 | そもそも見られていない | 「あなたの店・サービスを知ってる人、そもそもどれくらいいそう？」 | 露出を増やす（SNS・SEO・広告・紹介設計） |
| 興味 | 見られているが刺さっていない | 「SNSやサイトは見られてるのに反応が薄い？」 | 訴求の見直し（誰向けか・約束・プロフィール/導線） |
| 行動 | 興味は持たれるが購入・問い合わせに至らない | 「問い合わせ直前で消える人が多い？」 | LP・オファー・不安解消（→ lp-marketing） |
| 継続 | 一回きりで終わる | 「一度来た人、また来てくれてる？」 | リピート・紹介設計（メール/LINE・会員・特典） |

## 診断の手順

1. 数字があれば数字で切り分ける（インプレッション → クリック/プロフィールアクセス → CV → リピートの、どこで急落しているか）
2. 数字がなければ上の表の確認質問を投げ、回答から仮説を立てる
3. 判定は「認知の詰まりが本命（仮）」のように前提つきで見せ、訂正の機会を渡す
4. 詰まりが複数見えても、**一番上流の詰まりから1つずつ**着手する。認知ゼロで行動改善をしても検証できない

## 注意

- 「フォロワーを増やしたい」という依頼は認知の施策に聞こえるが、実際の詰まりは興味や行動のことが多い。依頼された手段でなくゴールから診断する
- 新規獲得（認知〜行動）と再訪（継続）はコストが桁違い。継続の詰まりを放置して新規に投資する構図になっていたら指摘する
