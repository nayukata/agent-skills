# マーケティングブリーフ（Web全般）

施策の話を始める前に埋める土台。全部埋まるまでチャネルの議論を始めない。

## テンプレート

| 項目 | 書くこと |
|---|---|
| 商品・サービス | 何を売っているか（1行） |
| ビジネスのゴール | 最終的に増やしたい数字を**1つ**（月の売上 / 問い合わせ数 / 来店数 / 採用応募数など）。「認知度」で止めず、その先の行動まで |
| ターゲット | 誰が買うか。属性（30代女性）より状況（「引っ越してきたばかりで近所の店を知らない」）で描く |
| 痛み・欲求 | 買う前に何に困っているか、どうなりたいか |
| 約束（ベネフィット） | この商品で生活・仕事がどう変わるか |
| 証拠 | 約束を信じてもらう材料（実績数値・利用者の声・データ・資格・メディア掲載） |
| 選ばれる理由 | 競合や代替手段（何もしない、を含む）でなくこれを選ぶ理由 |
| 現状の集客 | 今、客はどこから来ているか。運用中のチャネル（サイト / SNSアカウント / 顧客リスト / 店頭）とその状態 |
| 使えるリソース | 週に使える時間、月の予算、続けられる人は誰か、作れる素材（写真・動画・文章のどれが得意か） |

LP専用ブリーフとの違いは下2行。**Web全般では「現状」と「リソース」がチャネル選定を決める**ため、必ず埋める。

## 仮埋めの手順

1. 依頼文と手持ち情報から**全項目**を仮埋めする。推測した項目には（仮）を付ける
2. 表ごと見せて「違うところだけ教えて」と渡す。ゼロから書かせない
3. 割れやすい項目（ターゲット、ゴール）は AskUserQuestion で選択肢にする
   - 選択肢は3〜4個。自分の仮説を先頭に置き「（おすすめ）」と明示する
   - 誘導にならないよう、方向の違う妥当な選択肢を混ぜる
4. 確定版ブリーフを以後の全判断の基準にする

## 日常語の質問例

マーケ用語（ペルソナ、ファネル、KPI、リード）を使わずに聞く。

- ゴール: 「最終的に何の数字が増えたら『うまくいった』と言える？」
- ターゲット: 「一番喜んで買ってくれてるのは、どんな状況の人？」
- 現状: 「今来てるお客さんって、どこであなたを知った人が多い？」
- リソース: 「宣伝に使えるのは、ざっくり週何時間くらい？お金はかけられる？」
- 素材: 「写真・動画・文章、作ってて一番苦じゃないのはどれ？」

## よくある落とし穴

- **ゴールが「認知度を上げたい」**: 認知は手段。その先に取ってほしい行動（来店・問い合わせ・購入）まで聞き出して数字にする
- **ターゲットが「みんな」**: 全員向けは誰にも刺さらない。一番濃い1人に絞る
- **リソースを聞かずにチャネルを提案**: 週2時間の人に毎日投稿の運用を提案しても続かない。続かない施策は無い施策より悪い（アカウントの放置は不信感を生む）
- **既存資産の無視**: 顧客リストや常連客がいるのに新規獲得だけ考える。既存客の再訪・紹介のほうが安いことが多い
