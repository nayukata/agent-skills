# SNS運用の設計

## 原則

- **フォロワー数でなく「見込み客に届いているか」**。1万人の無関係なフォロワーより100人の近所の見込み客。数字の目標をフォロワー数に置かない
- **SNS単体で売ろうとしない**。SNSの仕事は認知と興味まで。行動はプロフィールの導線の先（LP・予約ページ・DM）で起こす
- **バズより継続**。当たり投稿を狙うより、続けられる頻度で淡々と積む。放置アカウントは不信感を生むので、続かないなら始めない

## プロフィールはLPと同じ

投稿が刺さった人は必ずプロフィールに来る。ここが弱いと投稿の努力が全部漏れる。
- 何者か・誰の役に立つかが1行でわかる
- フォローする理由がある（「フォローすると◯◯がわかる」）
- 行動導線が1つある（予約リンク・LP・LINE登録。並べすぎない）

## 投稿の型（配分の目安）

| 型 | 内容 | 配分 |
|---|---|---|
| 役立ち | ターゲットの悩みに答える。保存・共有される | 5割 |
| 共感・裏側 | 人柄・現場・失敗談。信頼と親近感 | 3割 |
| 実績・宣伝 | 商品・実績・お知らせ | 2割 |

宣伝ばかりのアカウントはフォローする理由がない。逆に役立ちだけで商売の話をゼロにすると行動につながらない。

## 媒体の文化に合わせる

同じ内容の全媒体コピペ投稿は効かない。媒体ごとに「見られ方」が違う。
- X: 文字で語る。リアルタイム性と会話（リプライ・引用）が伸ばす
- Instagram: 1枚目の画像で止める。保存されるまとめ系が伸びる。ストーリーズで日常と距離の近さを出す
- TikTok / リール: 冒頭1秒で決まる。フォロワー外に届く前提で、文脈なしで伝わる作りに

## 継続の設計

- 週の投稿数を先に決める（リソースから逆算。盛らない）
- ネタは都度考えない。ブリーフの「痛み・欲求」から質問リストを作り、投稿ネタとしてストックする（客に聞かれたことは全部ネタ）
- 月1回、伸びた投稿と伸びなかった投稿を見比べて配分を調整する
