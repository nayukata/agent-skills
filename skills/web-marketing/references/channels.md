# チャネル特性と選定

チャネルは「ターゲットがいる場所 × 商材との相性 × 続けられるリソース」で選ぶ。最初は1〜2個に絞る。

## 一覧表

| チャネル | 向く場面 | 効くまでの時間 | 必要リソースの目安 | 効くファネル段階 |
|---|---|---|---|---|
| SEO・ブログ | 検索される悩み・比較がある商材。記事が資産として残る | 3〜6ヶ月 | 週1本の記事を書き続ける体制 | 認知〜興味 |
| X（旧Twitter） | テキスト文化。BtoB・開発者・時事性のある発信。拡散が速い | 1〜3ヶ月 | 毎日〜週数回の投稿と反応 | 認知 |
| Instagram | ビジュアルで魅力が伝わる商材（飲食・美容・店舗・物販）。世界観づくり | 3〜6ヶ月 | 週数回の写真/リール + ストーリーズ | 認知〜興味 |
| TikTok / Shorts / リール | 若年層への認知獲得。フォロワーゼロでも届く | 当たれば即〜3ヶ月 | 短尺動画を週数本、企画力 | 認知 |
| YouTube | 深い信頼構築。専門性を語れる商材。資産型 | 6ヶ月〜 | 企画・撮影・編集の体制（最重量級） | 興味〜行動 |
| メール / LINE公式 | 既存の見込み客・顧客の育成と再訪。リストが必要 | 即 | 週〜月数回の配信 | 行動・継続 |
| Web広告（検索連動） | 今まさに探している人を刈り取る。即効性 | 即 | 予算 + 受け皿のLP（→ lp-marketing） | 行動 |
| Web広告（SNS広告） | まだ探していない人への認知。ターゲティング | 即 | 予算 + クリエイティブ + LP | 認知〜行動 |
| Googleビジネスプロフィール | 実店舗・地域ビジネス。「地域名 + 業種」検索 | 即〜1ヶ月 | 登録と口コミ返信（最軽量） | 認知〜行動 |

## 選定の手順

1. ファネル診断で特定した詰まりの段階に効くチャネルに絞る
2. その中で、ターゲットが日常的にいる場所を優先する（ブリーフのターゲット像から推定し、確信がなければユーザーに日常語で聞く: 「お客さんって普段どのアプリ見てそう？」）
3. リソースで足切りする。続けられない運用は提案しない
4. 実店舗・地域ビジネスなら Googleビジネスプロフィール を最優先で確認する（無料・軽量・即効の割に見落とされがち）
5. 既に運用中のチャネルがあれば、新規追加より先に既存の改善を検討する

## 各チャネルの「最初の一歩」

施策に翻訳するとき、大きな計画でなく今週できる一歩から始める。

- SEO・ブログ: ターゲットが検索しそうな悩みの言葉を10個書き出し、競合の薄い1つで記事を書く
- メール / LINE: 既存客に「登録する理由」（クーポン・限定情報）を付けて登録導線を作る
- 検索連動広告: 「地域名 + 業種」「悩み + 解決策」のキーワードを少額で試し、受け皿のLPを lp-marketing で整える
- Googleビジネスプロフィール: 登録情報を埋め、写真を10枚載せ、既存客に口コミを1件依頼する
- SNS運用: [sns.md](sns.md) を参照

## 撤退基準もセットで渡す

チャネル提案時に「3ヶ月続けて見る数字が動かなければやめて次」と撤退基準を必ず添える。
やめる基準がないと、効かないチャネルに情が湧いて全リソースが沈む。
