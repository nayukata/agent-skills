# 計測と改善（Web全般）

## 北極星は1つ

ブリーフの「ビジネスのゴール」（月の問い合わせ数など）を北極星に置く。
チャネルの数字（フォロワー・PV・インプレッション）はすべて中間指標であって、北極星が動かなければ意味がない。

## ファネル対応の中間指標

診断したボトルネックに対応する数字を1〜2個だけ選んで渡す。全部は見ない。

| 段階 | 見る数字の例 |
|---|---|
| 認知 | インプレッション / リーチ / 検索表示回数 |
| 興味 | プロフィールアクセス / サイト訪問 / クリック率 / 保存・フォロー |
| 行動 | 問い合わせ・予約・購入数（CV）、LPのCVR |
| 継続 | リピート率 / LINE・メール登録数 / 口コミ数 |

計測の道具はチャネル付属の無料のもので始める（SNSのインサイト、GA4、Googleビジネスプロフィールのパフォーマンス）。道具選びに時間を使わない。

## 振り返りの周期

| 周期 | やること |
|---|---|
| 週次 | 見る数字を記録するだけ（5分）。一喜一憂しない |
| 月次 | 傾向を見て打ち手を1つ変える。SNSなら伸びた投稿/伸びない投稿の見比べ |
| 3ヶ月 | チャネルの継続判断。中間指標が動いていなければ撤退して次のチャネルへ |

## 改善の作法

- 1回に1箇所ずつ変える。同時に複数変えると何が効いたかわからない
- 中間指標は動いたのに北極星が動かない場合、次の段階（例: 認知は増えたが行動されない → LP・オファー）に詰まりが移った合図。ファネル診断に戻る
- 効いた訴求・伸びた投稿の学びはブリーフに反映する（「約束」や「ターゲット」の解像度が上がる）。ブリーフが育つほど次の施策が当たりやすくなる
