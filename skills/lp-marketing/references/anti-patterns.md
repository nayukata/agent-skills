# 公開前チェック（アンチパターン）

ユーザーに見せる前・公開前に全項目を確認する。1つでも該当したら直してから見せる。
既存LPの診断にもこのリストを使う。

## 戦略

- [ ] ターゲットが「みんな」のままになっている
- [ ] CTAのゴールが対等に2つ以上ある
- [ ] 主張に証拠が1つも添えられていないセクションがある
- [ ] 流入経路とファーストビューのメッセージがずれている

## ファーストビュー

- [ ] 3秒見て何のページかわからない
- [ ] キャッチコピーが商品名・社名・理念で、ターゲットへの約束になっていない
- [ ] ファーストビュー内にCTAがない

## コピー

- [ ] 機能の羅列で終わっている（便益に翻訳されていない）
- [ ] 「高品質」「充実」など中身のない形容詞が残っている
- [ ] 会社の自分語りが証拠より先・より長く置かれている
- [ ] 根拠のない断定・誇大表現がある（景品表示法・薬機法のリスク）

## 行動導線

- [ ] フォームの入力項目が必要最小限を超えている
- [ ] CTAボタンの文言が「送信」「登録」など、行動の結果を語っていない
- [ ] 不安への先回り（FAQ・保証・マイクロコピー）が1つもない
- [ ] 長いLPなのにCTAが1箇所にしかない

## 計測

- [ ] CVイベントが計測できない状態で公開しようとしている
- [ ] 流入経路が区別できない（全部「直接流入」に見える）状態になっている
