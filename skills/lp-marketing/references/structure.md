# LP構成への翻訳

ブリーフと温度感が決まったら、セクション構成に落とす。
実装前に構成案（セクションごとの役割 + 載せる内容の1行サマリ）を見せて合意を得る。

## 基本の背骨（上から順に）

| # | セクション | 役割（ブリーフとの対応） |
|---|---|---|
| 1 | ファーストビュー | 約束を一目で伝える |
| 2 | 共感 | 痛み・欲求の言語化。「これ私のことだ」 |
| 3 | 解決策の提示 | 商品の登場。痛みがなぜ解決するか |
| 4 | ベネフィット | どうなれるか（3つ前後に絞る） |
| 5 | 証拠 | 利用者の声・実績・データ |
| 6 | 選ばれる理由 | 競合・代替手段との違い |
| 7 | オファー | 価格・特典・保証・期限 |
| 8 | 不安の先回り | FAQ。買わない理由を1つずつ潰す |
| 9 | クロージング | 約束の再確認 + CTA再掲 |

温度感による調整:
- 問題自覚以下 → 2〜3 を厚く。教育に紙幅を使う
- 商品自覚以上 → 2〜3 を圧縮または削除
- 最高温度 → 1→7→9 だけでいい。長いLPはむしろ邪魔

## ファーストビュー（最重要）

3秒で離脱が決まる。スクロールされなければ以降のセクションは存在しないのと同じ。

必須3要素:
1. **何のページか**が一目でわかる
2. **自分に関係あるか**がわかる（ターゲットが「私だ」と思う）
3. **次に何をすればいいか**がわかる（CTA）

キャッチコピーはブリーフの「約束」を、ターゲット自身の言葉で書く（型は copywriting.md）。

## CTA設計

- **ゴールは1つ**。「購入」と「資料請求」を対等に並べない。温度が割れるなら主CTA（目立つ）と副CTA（控えめなテキストリンク）の主従をつける
- ボタン文言は行動の結果を書く。「送信」→「無料で診断結果を受け取る」
- CTA直下に不安を消す一言（マイクロコピー）。「30秒で完了」「しつこい営業はしません」「いつでも解約OK」
- 長いLPでは画面2〜3枚分ごとにCTAを再掲する
- フォームは項目を必要最小限に。1項目減るごとに完了率は上がる

## 構成フレームの使い分け

迷ったら基本の背骨でいい。型を使いたい場合:

- **PASONA**（問題 → 共感 → 解決策 → 絞込 → 行動）: 温度が低い訪問者向け。悩み起点の商材
- **QUEST**（絞込 → 共感 → 教育 → 興奮 → 行動）: 広告流入で冒頭にターゲットを絞り込みたいとき

フレームは道具であって目的ではない。複数の型の全部盛りにしない。
