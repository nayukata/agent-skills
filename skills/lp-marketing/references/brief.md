# マーケティングブリーフ

LPの土台になる9項目。全部埋まるまで見た目の議論を始めない。

## テンプレート

| 項目 | 書くこと |
|---|---|
| 商品・サービス | 何を売るか（1行） |
| ゴール（CV） | 訪問者に取ってほしい行動を**1つ**（購入 / 予約 / 資料請求 / 登録など） |
| ターゲット | 誰が買うか。属性（30代女性）より状況（「子どもが寝た後の1時間しか自分の時間がない」）で描く |
| 痛み・欲求 | 買う前に何に困っているか、どうなりたいか |
| 約束（ベネフィット） | この商品で生活・仕事がどう変わるか |
| 証拠 | 約束を信じてもらう材料（実績数値・利用者の声・データ・資格・メディア掲載） |
| 選ばれる理由 | 競合や代替手段（何もしない、を含む）でなくこれを選ぶ理由 |
| 流入経路 | どこからLPに来るか（広告 / 検索 / SNS / 紹介 / QRコード） |
| 価格・オファー | 価格、特典、保証、期限 |

## 仮埋めの手順

1. 依頼文と手持ち情報から**全項目**を仮埋めする。推測した項目には（仮）を付ける
2. 表ごと見せて「違うところだけ教えて」と渡す。ゼロから書かせない
3. 割れやすい項目（ターゲット、選ばれる理由）は AskUserQuestion で選択肢にする
   - 選択肢は3〜4個。自分の仮説を先頭に置き「（おすすめ）」と明示する
   - 誘導にならないよう、方向の違う妥当な選択肢を混ぜる（「近い案のバリエーション4つ」にしない）
4. ユーザーの訂正を反映したら、確定版ブリーフを以後の全判断の基準にする

## 日常語の質問例

マーケ用語（ペルソナ、USP、コンバージョン）を使わずに聞く。

- ターゲット: 「これ、一番喜んで買ってくれそうなのはどんな状況の人？」
- 痛み: 「その人は今、何に困ってこれを探すんだろう？」
- 証拠: 「『本当に効くの？』って疑われたら、何を見せる？」
- 選ばれる理由: 「似た商品じゃなくてこっちを選ぶ理由って何だろう？」
- CV: 「このページで最終的に何をしてもらえたら成功？」
- 流入経路: 「このページ、みんなどこから来る予定？」

## よくある落とし穴

- **ターゲットが「みんな」**: 全員向けは誰にも刺さらない。一番濃い1人に絞る。他の客は絞っても来る
- **ベネフィットが機能説明のまま**: 「何ができるか」でなく「どうなれるか」まで翻訳する（詳細は copywriting.md）
- **証拠ゼロ**: 実績がなければ代替手段を提案する。無料モニターの声、開発者の顔と開発理由、返金保証、ビフォーアフター
- **ゴールが2つ**: 「購入も資料請求も」は両方弱くなる。温度感で主従を決める（詳細は structure.md のCTA設計）
