# 訪問者の温度感

同じ商品でも、訪問者が「どこまで知っているか」でLPの語り出しと長さが変わる。
流入経路から温度感を推定し、構成の深さを決める。

## 5段階（Eugene Schwartz の認知段階）

| 段階 | 訪問者の状態 | LPの語り出し |
|---|---|---|
| 無自覚 | 問題に気づいていない | 問題の指摘・気づきから。いきなり売り込まない |
| 問題自覚 | 困っているが解決策を知らない | 痛みへの共感から。「わかってくれてる」を先に作る |
| 解決策自覚 | 解決方法は知っているが商品を知らない | 「その方法ならこれが一番」の理由から |
| 商品自覚 | 商品を知っているがまだ買っていない | 比較・不安解消・オファーから |
| 最高温度 | ほぼ買う気でいる | 最短でCTAへ。余計な説明で邪魔しない |

## 流入経路からの推定

| 流入 | 温度感の目安 |
|---|---|
| 指名検索（商品名・社名）、リピーター | 商品自覚〜最高温度 |
| 比較キーワード検索（「◯◯ おすすめ」「A B 違い」） | 解決策自覚 |
| 悩みキーワード検索（「肩こり ひどい 治らない」） | 問題自覚 |
| SNS・ディスプレイ広告（受動的に目に入る） | 無自覚〜問題自覚 |
| 紹介・口コミ・インフルエンサー経由 | 商品自覚（紹介者の信頼を借りられている） |

## 使い方

- **温度が低いほどLPは長くなる**（共感と教育のセクションが必要）。温度が高いほど短くていい
- 流入が複数あるなら、量が一番多い経路に合わせる
- 温度感が大きく割れる流入が両方太いなら、LPを分けることを提案する（1枚で全員に語ろうとしない）
- 広告運用がある場合、広告文とLPの語り出しの一致が最重要（詳細は measurement.md の改善優先順位）
