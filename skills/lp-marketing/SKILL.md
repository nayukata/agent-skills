# LP Marketing

LPの成果はデザインの前に決まる。「誰に・何を・なぜ信じてもらうか」が曖昧なまま作ったLPは、綺麗でも売れない。
このスキルは、マーケティングの知識がないユーザーからでも戦略を引き出し、LPの構成・コピー・計測設計まで翻訳する。

## 原則

1. **見た目の前に戦略**。色やレイアウトの議論は、ブリーフが確定してからしか始めない。
2. **マーケ用語をユーザーに持ち込まない**。質問は日常語で行い（「これ、一番喜んで買うのはどんな人？」）、フレームワークへの翻訳はこちらの仕事。報告も日常語で返す。
3. **言われなかったことは仮説で埋め、仮説は隠さない**。仮埋めしたブリーフを見せて、訂正の機会を渡す。ユーザーは「何が欲しいか」は言えなくても「どこが違うか」は即答できる。
4. **1つのLPに1つのゴール**。CTA（行動喚起）を複数ゴールに散らさない。迷ったら削る。
5. **公開はスタートであってゴールではない**。計測と改善の設計までがLP制作。

## フロー

チェックリストで進捗を管理する（タスク管理ツールでも応答本文への記載でもよい）:

```
- [ ] 1. マーケティングブリーフ仮埋め
- [ ] 2. 訪問者の温度感判定
- [ ] 3. LP構成への翻訳
- [ ] 4. コピー執筆
- [ ] 5. 公開前チェックと計測設計
```

### 1. マーケティングブリーフ仮埋め

[references/brief.md](references/brief.md) のテンプレートを、依頼文と手持ち情報から全項目仮埋めして見せる。
推測した項目には（仮）を付け、「違うところだけ教えて」と渡す。
割れやすい論点（ターゲット、選ばれる理由）は、表を見せたのと同じターンで1回の AskUserQuestion にまとめて聞く（2問程度まで）。表の他の項目の訂正は、選択肢の「その他」欄や次のやり取りで自由記述として受ける。

### 2. 訪問者の温度感判定

[references/awareness.md](references/awareness.md) を参照し、流入経路から訪問者の温度感を推定する。
温度感はLPの長さと語り出しを決める。ここを飛ばすと「正しいのに刺さらない」LPになる。
流入経路が（仮）のままでも止まらない。暫定判定で先に進み、判定結果に「流入が◯◯という前提」と明示して、前提が変わったらここに戻る。

### 3. LP構成への翻訳

[references/structure.md](references/structure.md) を参照し、ブリーフと温度感をセクション構成に落とす。
構成案（各セクションの役割と載せる内容の1行サマリ）を見せて合意を得てから実装に入る。
見た目の方向性が曖昧な場合、design-hearing スキルが使えるなら接続する（無ければそのまま進める）。

### 4. コピー執筆

[references/copywriting.md](references/copywriting.md) を参照し、機能をベネフィットに翻訳して書く。
キャッチコピーは複数案を実物（モック上）で見せて選んでもらう。テキストの箇条書きで選ばせない。

### 5. 公開前チェックと計測設計

[references/anti-patterns.md](references/anti-patterns.md) の全項目をセルフチェックし、該当ゼロにしてから見せる。
[references/measurement.md](references/measurement.md) を参照し、CV計測と改善の見方をユーザーに引き継ぐ。

## 既存LPの改善相談のとき

「なんか反応が悪い」も正規の入力として扱う。原因の言語化をユーザーに求めない。
1. 現状のLPからブリーフを逆算して見せる（「このLPは◯◯な人に△△を約束しているように読める」）
2. 数字があれば [references/measurement.md](references/measurement.md) の切り分け表で問題箇所を特定する
3. 数字がなければ [references/anti-patterns.md](references/anti-patterns.md) で診断し、影響の大きい順に直す
